# Nginx Labs

> _"It worked on the first try."_
>
> — Definitely not me.

This repository is my hands-on Nginx playground.

Instead of collecting configuration snippets, I'm building and breaking things to understand **how Nginx actually works**—from serving a single HTML page to reverse proxies, load balancing, caching, security, and HTTPS.

Every section is an independent lab that builds on the previous one, making it easy to revisit concepts, experiment freely, and learn from things that inevitably break.

## Tech Stack

- Nginx
- Docker & Docker Compose
- Linux
- Git

Future labs may also include:

- FastAPI
- Django
- Laravel
- Redis
- PostgreSQL

## Philosophy

I prefer learning by answering questions like:

- What happens if I remove this directive?
- Why does Nginx behave this way?
- How does a request actually flow through the server?
- What problem is this feature solving?

If something breaks, that's usually where the interesting learning starts.

---

_This repository grows one experiment at a time—from a single Nginx container to production-style infrastructure._
